# sprint4
REST API для блог-платформы с постами, комментариями, лайками и изображениями.
## Функциональность

### Посты
- ✅ Создание поста с заголовком, текстом и тегами
- ✅ Получение поста по ID
- ✅ Получение списка постов с пагинацией и поиском
- ✅ Обновление поста
- ✅ Удаление поста
- ✅ Добавление лайков к посту
- ✅ Загрузка и получение изображения для поста

### Комментарии
- ✅ Получение комментариев к посту
- ✅ Получение конкретного комментария
- ✅ Создание комментария
- ✅ Обновление комментария
- ✅ Удаление комментария

## API Endpoints

### Посты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/posts?search=&pageNumber=1&pageSize=10` | Получить посты с пагинацией |
| GET | `/posts/{id}` | Получить пост по ID |
| POST | `/posts` | Создать новый пост |
| PUT | `/posts/{id}` | Обновить пост |
| DELETE | `/posts/{id}` | Удалить пост |
| POST | `/posts/{id}/likes` | Добавить лайк к посту |
| PUT | `/posts/{id}/image` | Загрузить изображение для поста |
| GET | `/posts/{id}/image` | Получить изображение поста |

### Комментарии

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/posts/{postId}/comments` | Получить комментарии к посту |
| GET | `/posts/{postId}/comments/{commentId}` | Получить конкретный комментарий |
| POST | `/posts/{postId}/comments` | Создать комментарий |
| PUT | `/posts/{postId}/comments/{commentId}` | Обновить комментарий |
| DELETE | `/posts/{postId}/comments/{commentId}` | Удалить комментарий |
